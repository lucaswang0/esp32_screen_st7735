# Weather Clock - ESP32-C3 ST7735 温湿度时钟

基于 ESP32-C3 和 ST7735 1.44" 128×128 TFT 显示屏的温湿度时钟项目，带有翻页时钟动画效果。

## 功能特性

- **翻页时钟显示**：首页时间采用翻页动画效果，显示完整的 HH:MM:SS
- **双页面轮换显示**：时钟页面和图表页面每 10 秒自动切换
- **实时温湿度监测**：支持两个 DHT11 传感器
- **WiFi 配网**：支持 AP 配网模式，首次连接失败自动开启热点
- **NTP 时间同步**：自动从阿里云 NTP 服务器同步时间
- **传感器历史记录**：按日期保存传感器数据到 SPIFFS 文件
- **背光亮度控制**：支持 0-100% PWM 调光
- **RSSI 信号强度显示**：实时显示 WiFi 信号强度

## 硬件配置

### 引脚定义

| 引脚 | 功能 |
|------|------|
| GPIO0 | TFT CS |
| GPIO1 | TFT DC |
| GPIO2 | TFT RST |
| GPIO3 | TFT MOSI |
| GPIO4 | TFT SCLK |
| GPIO5 | TFT BL (背光) |
| GPIO6 | DHT11 #1 |
| GPIO7 | DHT11 #2 |

### 屏幕参数

- 型号：ST7735S
- 分辨率：128×128
- 接口：SPI
- 刷新率：40MHz

## 使用说明

### 首次启动

1. 烧录固件到 ESP32-C3
2. 首次连接 WiFi 失败时，设备会自动创建热点 `ESP32-Weather`
3. 使用手机连接该热点
4. 在浏览器中打开 `192.168.4.1` 配置 WiFi 网络
5. 配置成功后设备会自动重启并连接 WiFi

### WiFi 重连

- 设备会自动检测断连并尝试重连
- AP 配网模式 10 分钟无活动自动关闭

### 传感器数据

- 每 5 分钟采样一次传感器数据
- 数据保存到 SPIFFS 文件 `/sensor1_YYYY-MM-DD.dat` 和 `/sensor2_YYYY-MM-DD.dat`
- 每天 0 点自动重置历史数据

## 配置参数

在 `main.cpp` 中可以修改以下配置：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `BACKLIGHT_PERCENT` | 80 | 背光亮度百分比 (0-100) |
| `PAGE_SWITCH_INTERVAL` | 10000 | 页面切换间隔 (毫秒) |
| `SAMPLE_INTERVAL` | 300000 | 传感器采样间隔 (毫秒) |
| `WIFI_CHECK_INTERVAL` | 5000 | WiFi 检查间隔 (毫秒) |
